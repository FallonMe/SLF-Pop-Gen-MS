# Reuse and attribution

Citation information is provided in CITATION.cff. No new license is applied by this packaging change: the historical GitHub branches do not contain a license file, and third-party snippets and coauthored materials need to retain their original rights and attribution.

The paper's publication license does not automatically establish a license for every script, dataset, or incorporated snippet. Before adding a repository-wide LICENSE, confirm the intended license for original code and the applicable terms for external code and environmental data. Public visibility alone should not be interpreted as a blanket reuse grant.

External tools retain their own licenses and should be cited as described in the published Methods. Third-party snippets embedded in workflow notes should be checked against their original source before redistribution under a new code license.
