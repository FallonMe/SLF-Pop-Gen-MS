Overview

This repository contains the scripts, data, and analysis pipeline used in our study on the population genomics of the invasive spotted lanternfly (Lycorma delicatula) in the Northeastern United States. 
The study investigates genetic diversity, population structure, and demographic history to understand the invasion dynamics of the spotted lanternfly, with a particular focus on the role of urbanization.

Main Branch
Momi2 with mutation rate.ipynb
Jupyter notebook containing the momi2 analysis, including the mutation rate calculations used for inferring the demographic history of the spotted lanternfly populations.
Momi2 with mutation rate.md
A markdown version of the Momi2 notebook, providing a text-based overview of the analyses conducted in the Jupyter notebook.
SLF R code Final.V01.Rmd
R Markdown script containing the R code used for genetic diversity, population structure, and isolation by distance/environment analyses.
SLF_Analysis_Pipeline_HPC
High-performance computing (HPC) pipeline scripts used for processing genomic data, including sequence alignment, variant calling, filtering steps and other analysis.

Metadata Branch
Metadata for 98 SLF and Environmental Data
Contains metadata files for the 98 spotted lanternfly samples used in the study, along with all associated environmental data. This includes collection information, GPS coordinates, and environmental variables used in the analyses.
